## 0. Phase 매핑 개요

marketing/05의 시간축(D1~D180)을 GSD phase로 분해. 각 phase는 PLAN.md를 가지며 wave-based 실행 가능.

| GSD Phase | 시간 | marketing/05 대응 | 핵심 산출물 |
|-----------|------|--------------------|-------------|
| **phase-1** | D1~D7 | Phase 1 Week 1 | 채널 개설 + 아바타 + 도구 셋업 + 트레일러 |
| **phase-2** | D8~D14 | Phase 1 Week 2 | 트레일러 발행 + EP01 발행 |
| **phase-3** | D15~D21 | Phase 1 Week 3 | EP02 + 쇼츠 2편 + LinkedIn 첫 카루셀 |
| **phase-4** | D22~D30 | Phase 1 Week 4 | EP03 + EP04 + 첫 뉴스레터 |
| **phase-5** | D31~D60 | Phase 2 전반 | 발행 리듬 락인 (월 4롱폼+8쇼츠) |
| **phase-6** | D61~D90 | Phase 2 후반 | LinkedIn 본격 + D60 회고 분석 |
| **phase-7** | D91~D180 | Phase 3 | 권위 형성 + D150 90일 보고서 PDF |
| **phase-8** | D180+ | 분기점 결정 | A/B/C 분기 선택 |

## 1. Phase 1 — Week 1 인프라 (D1~D7)

**목표:** 채널 골격을 0에서 1까지 구축. 트레일러 발행 직전까지.
**의존성:** 없음 (시작점)
**예상 시간:** 11시간 (1주 박대표 상한)

### 핵심 작업
- D1: YouTube 채널 개설 + LinkedIn 정비
- D2: 박대표·문실장 일러스트 아바타 1차 시드 (Midjourney/DALL-E)
- D2: 채널 배너·프로필 (Canva, S3 색감)
- D3: 아바타 표정 풀 6~8종 확정 + About 등록
- D3: ElevenLabs 음성 클로닝 1차 학습 (5~10분 샘플)
- D4: Descript·Stibee 셋업
- D5: 트레일러 90초 스크립트 (헌법 + 명제 + 청중 약속 압축)
- D6: 트레일러 영상 합성 (아바타 + 클로닝 음성 + 실 화면)
- D7: 트레일러 발행 + LinkedIn·뉴스레터 동시 공지

**완료 기준:** Week 1 종료 시 트레일러 1편 라이브 + 도구 풀스택 가동.

→ 상세: `phases/phase-1-week1-infrastructure/PLAN.md`

## 2. Phase 2 — Week 2 EP01 발행 (D8~D14)

**목표:** Format A (이야기 한 편) 첫 영상 발행으로 운영 리듬 검증.
**의존성:** Phase 1 (도구 셋업·아바타·음성 클로닝 완료)
**예상 시간:** 11시간

### 핵심 작업
- 권장: **S1 EP001 "코딩을 모르는 CEO가 개발자가 되다"** 영상화
- 두려움 노출 1줄: 시작 전 박대표 막연함 (이 부분만 본인 실음성, ElevenLabs 금지)
- 인트로 30초 + 본문 7~10분 + 엔딩 30초
- 실 화면 녹화 / 인용 카드 / 박대표 아바타 클로즈업

**완료 기준:** EP01 라이브 + 시청 유지율 첫 측정 시작.

**목표:** Format B (오늘의 빌드) 검증 + 쇼츠 그로스 루프 시작.
**의존성:** Phase 2 (영상 워크플로우 1회 완주 검증)

### 핵심 작업

## 4. Phase 4 — Week 4 EP03 + EP04 + 뉴스레터 (D22~D30)

**목표:** 5개 포맷 중 4개 검증 완료 + 뉴스레터 첫 발행.
**의존성:** Phase 3

### 핵심 작업
- **EP03** (Format C 숫자 한 개): S1 EP008 "22개 프로젝트, 1명"
- **EP04** (Format D 에세이 영상): S3 Interlude "AI를 조합하는 기술"
- 첫 뉴스레터: 4편 회고 + 다음 달 예고

### Phase 1(블록) 종료 시점 자가 점검
- [ ] 4편 모두 헌법 5계명 통과?
- [ ] 박대표 주 11시간 상한 안에서 운영?
- [ ] "처음 시작했다" 댓글 1개+?
- [ ] 평균 시청 유지율 50%+?

> 4가지 중 3개 미만 통과 시 Phase 5 진입 전 **리듬 재조정** (발행 빈도 감소).

## 5. Phase 5 — Settle 전반 (D31~D60)

**목표:** 발행 리듬 안정화 (60일 무중단의 절반).
**의존성:** Phase 4 자가 점검 통과

### 핵심 작업
- 월간 영상 라인업 락인:
  - 월 1: A · A · B · D
  - 월 2: A · B · C · B
- 댓글 24시간 내 답신 (박대표 본인)
- 뉴스레터 주 1회

## 6. Phase 6 — Settle 후반 + LinkedIn 본격 (D61~D90)

**목표:** Tier 1 도달 채널 LinkedIn 본격 구축 + D60 데이터 분석.
**의존성:** Phase 5

### 핵심 작업
- LinkedIn: 주 1 카루셀 + 주 1 영상 클립
- 브런치: 격주 1편 (HTML 에세이 → 글 재가공)
- D60 시청 유지율 패턴 분석 (8편)
- D90 KPI 측정:
  - 영상 누적: 16롱폼+32쇼츠
  - "처음 시작" 댓글: 10건+
  - 시청 유지율: 45%+
  - 뉴스레터: 200명+
  - LinkedIn: 500명+

## 7. Phase 7 — Compound 권위 형성 (D91~D180)

**목표:** Tier 2 → Tier 1 전환 흐름 검증 + 외부 인용 시작.
**의존성:** Phase 6 KPI 통과

### 핵심 작업
- 가장 강한 포맷에 30% 가중
- 외부 게스트 1회 시도 (데코페이브 직원 인터뷰 — 회사 홍보 아닌 변화 기록)
- 강연·인터뷰 요청 선별 수락 (Tier 1 매체만)
- D150: "박대표 90일 보고서" 무료 PDF 발행 → 뉴스레터 인센티브
- D180 KPI: 32롱폼+64쇼츠, "처음 시작" 50건+, 시청 유지율 50%+

## 8. Phase 8 — D180 분기점 결정

**목표:** 6개월 운영 결과로 향후 방향 1가지 선택.
**의존성:** Phase 7

### 분기 옵션
- **분기 A 지속**: KPI 1·2·3차 안정 → 변화 없이 유지
- **분기 B 확장**: 외부 인용·강연 임계점(월 5건+) → 도서·강연 별도 트랙 (채널 톤 격리)
- **분기 C 축소**: 헌법 위반 신호 감지 → 강제 감속 (주 1 → 격주 1)

> 어느 분기든 헌법은 그대로. 형식만 바뀐다.
